Find the files
search engines bury.

Search the open web for what ordinary search skips — documents, forms, notices and data sitting in upload folders, portals and old directories. Results are matched exactly as you type them, nothing is quietly removed, and you can always see why something matched.

!
No popularity ranking. No quiet filtering.

What you get is the material a normal results page demotes or drops: the PDF in /uploads/2019/03/, the notice behind a portal search, the “Index of /” listing nobody linked, the spreadsheet in a data dump. Your words are matched exactly — no stemming, no synonyms, no guessing — and nothing is taken out of the results: duplicates are labelled, low-quality pages are marked and moved to the end. Type a file type (pdf, apk, csv) to keep only that kind of file.

    Similar links

    find every other link shaped like this one

    Paste a link you already have. Its shape is kept — an id becomes a wildcard, so /forms/d/e/{id}/viewform stays and the id does not — and every link with the same shape turns up. Add a word or phrase to keep only the links that mention it. The ones it rejects are still listed underneath, so a strict phrase never looks like an empty web.

    Pasted links — pages nothing links to

    no search engine involved

    A portal’s search form, an unlinked annex, a sitemap entry nothing points at, an attachment behind a JavaScript link, a page the site deleted — none of that can be ranked by an engine that never crawled it. Paste the exact links and Nighthawk crawls from them and then tells you, per result, why nothing else could have found it. Same rules as the rest of the engine: matches are verbatim, ordering is newest-first, and nothing is removed.

    Run it yourself

    no configuration, no API keys
    ./run.sh api :8000 · web :3000
    docker compose up -d --build self-hosted VPS
    python scripts/selftest.py 20 end-to-end assertions
    python3 -m http.server 8080 serve this page alone
    This page is a standalone launcher — one file, no build step. Drop it on Vercel, Netlify, S3 or a USB stick. It has no server dependency: set the engine URL in engine settings (or leave it blank when it is served from the same origin as the app). The crawler itself needs a long-running host, so the API lives on a VPS or in Docker.
